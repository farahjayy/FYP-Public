# FYP Report — Formatting Specifications
*(Compiled from FYP_Guideline.pdf and FYP_Report_Template.pdf)*

---

## 1. Font & Spacing (Main Text)

| Element | Specification |
|---|---|
| Font | Times New Roman, regular style |
| Font size | 12 pt (body text) |
| Line spacing | 1.5 lines |
| Paragraph spacing | 3 lines between paragraphs |
| Paper size | White A4 |
| Printing | Interim report = double-sided; hard-bound dissertation = single-sided |

**Single-spaced exceptions:**
- Tables and figures
- Computer programs / source code (must also be reduced to **font size 8**)

**Paragraph indentation:** Subsequent (non-first) paragraphs in a subsection should be indented **1.27 cm (0.5 inch)** from the left margin. First paragraph after a heading aligns flush with the left margin. All paragraph text is **justified**.

---

## 2. Margins

| Side | Margin |
|---|---|
| Top | 25 mm (1.0") |
| Bottom | 25 mm (1.0") |
| Right | 25 mm (1.0") |
| **Left** | **40 mm** (wider — for binding) |

All paragraphs start at the left margin. Tables/figures must respect the same margins as body text.

---

## 3. Headings

Maximum of **3 numbered heading levels**:
```
1. FIRST-LEVEL HEAD
1.1 Second-Level Head
1.1.1 Third-Level Head
```

| Level | Style | Size |
|---|---|---|
| Chapter / major heading (Level 1) | Times New Roman, **bold, ALL CAPS** | 14 pt |
| Secondary heading (Level 2) | Times New Roman, bold, Title Case | 12 pt |
| Tertiary heading (Level 3) | Times New Roman, bold, Title Case | 12 pt |

**Layout rules:**
- Spacing between chapter title and first line of text: **4.5 lines**
- Spacing between a subsection title and its first line of text: **1.5 lines**
- Spacing between last line of text and next subsection title: **4.5 lines**
- A new chapter must always start on a **new page**
- A subsection title or new paragraph must **not** begin on the last line of a page

---

## 4. Tables & Figures

- Numbered **consecutively** (e.g., Table 1, Table 2… / Figure 1, Figure 2…)
- **Table caption/heading** → positioned at the **top**, centred
- **Figure caption/number** → positioned at the **bottom**, centred
- If smaller than a page, insert near point of reference with **3-line spacing** from surrounding text; keep tables on the same page (don't split)
- Every table/figure must be referred to in text *before* it appears (e.g., "Figure 1 shows…")
- Single line spacing applies to text inside tables/figures

---

## 5. Mathematical Equations

- Must be spaced out, centred
- Equation number aligned to the **right margin**, e.g. `(1.1)`
- Superscripts/subscripts clearly shown
- Spacing between last line of text and an equation: 1.5 lines
- Spacing between equation and following text: 1.5 lines

---

## 6. Pagination

- All pages numbered in sequence (introduction → end, including figures/tables/appendices)
- **Front matter** (before Chapter 1) uses lowercase Roman numerals: i, ii, iii…
- Page numbers: **bottom, centred**, no brackets/hyphens/decorative symbols

---

## 7. Citation & Referencing Style — APA or IEEE

You may use **either APA or IEEE** (check with your supervisor which is preferred for your area) — but be **consistent throughout**.

### IEEE style (numbered)
- In-text: numbered sequentially by order of first mention, in square brackets on the line (not super/subscript): `[1]`, `[2]`
- Repeated citation of the same source reuses the same number
- Multiple citations: `[1], [3], [5]` (preferred) or `[1-5]` for a range
- Reference list ordered numerically (order of first appearance), not alphabetically
- Example (journal): `K. P. Dabke and K. M. Thomas, "Expert system guidance for library users," Library Hi Tech, vol. 10, (1-2), pp. 53-60, 1992.`
- Example (book): `C. W. Lander, Power Electronics, 3rd. ed., London: McGraw-Hill, 1993.`

### APA style (author-date)
- In-text: (Author, Year) — as seen in the template, e.g. (Warner, 2002), (Chang et al., 1995)
- Reference list ordered **alphabetically** by author surname

**Note:** Citations are **not allowed in the Technical Paper abstract**.

## 8. Report Structure & Order of Contents

### FYP 1 — Interim Report (max 20 pages, excl. appendices)
1. Title Page
2. Abstract (max 1 page)
3. Chapter 1: Introduction — Background / Problem Statement / Objectives & Scope
4. Chapter 2: Literature Review and/or Theory
5. Chapter 3: Methodology / Project Work
6. Chapter 4: Conclusion and Future Work
7. References
8. Appendices

### Full Dissertation / Template structure (front matter order)
```
Declaration
Approval for Submission
Acknowledgements
Abstract
Table of Contents
List of Tables
List of Figures
List of Symbols / Abbreviations
List of Appendices
CHAPTER 1: INTRODUCTION
CHAPTER 2: LITERATURE REVIEW
CHAPTER 3: METHODOLOGY
CHAPTER 4: RESULTS AND DISCUSSION
CHAPTER 5: CONCLUSION AND RECOMMENDATIONS
REFERENCES
APPENDICES
```

**Abstract:** ≤ 1 page — covers purpose, scope, methodology, results, conclusion.
**Acknowledgements:** ≤ 1 page.
**Table of Contents:** must list all headings/sub-headings, tables, figures, appendices, and bibliography with page numbers (plus certification/abstract/acknowledgement if applicable).

---

## 9. Technical Paper (FYP 2) — Separate, Stricter Format

| Element | Specification |
|---|---|
| Length | Max 6 pages (max 5,000 words) |
| Abstract | < 300 words, single-spaced, **no citations allowed** |
| Keywords | Max 6, must not repeat title words |
| Font | Times New Roman 11 **or** Arial 10 |
| Line spacing | 1.5 |
| Margins | 1 inch (2.5 cm) — top, bottom, left, right (all equal, unlike the main report) |
| Layout | Single-column |
| Equations | MathType format |
| Citation style | **IEEE only** |
| Figures/Tables | Labelled and embedded directly in text |
| Headings | Max 3 subheading levels |

---

## 10. Length Limits

| Document | Max Length (excl. appendices) |
|---|---|
| Interim Report (FYP 1) | 20 pages |
| Technical Paper (FYP 2) | 6 pages |
| Dissertation | 50 pages |

---

## 11. General Writing Style

- Brief, straightforward wording
- Passive voice encouraged
- Avoid jargon
- Every table/figure must be pre-announced in the text
- No new chapter starting mid-page; no orphan headings/paragraphs at page bottom

---

## 12. Academic Integrity

- All ideas/words/data taken from others must be cited (APA or IEEE)
- Plagiarism = zero marks (FYP1) or grade **F** (FYP2)
- University owns copyright of all findings, designs, and IP produced

---

## 13. Grading Relevance (why this matters)

Under "Organisation and Clarity" (15 marks), examiners specifically score:
- Compliance with standard guidelines & formatting
- English usage and writing skills
- Referencing and citations following the style guide correctly

Formatting errors directly cost marks — not just "cosmetic" feedback.
