# PaySense — Final Year Project (public record)

**PaySense: an AI-driven decision support system for financial health forecasting and BNPL risk classification for Malaysian university students.**

Final Year Project, Bachelor of Computer Science (Hons), Universiti Teknologi PETRONAS.
Student: Nur Farah Binti Ahmad Nazri · Supervisor: Dr. Nazleeni Samiha Bt Haron.

This repository is the public, sanitized record of the project's documents for examiners and advisors. It contains the author's own deliverables and model-evaluation artefacts. Personal financial data, signed forms, recordings, other students' work and copyrighted reference papers are deliberately not included.
